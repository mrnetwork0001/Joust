# Desktop plugin smoke harness

`smoke.mjs` exercises `desktop/plugin.js` without Hermes Desktop: it registers Node module hooks that rewrite the plugin's bare imports the way the Desktop runtime loader does (`@hermes/plugin-sdk` → `sdk-stub.mjs`, `react*` → a scratch `node_modules`, anything else refused), calls `register(ctx)` with a recording context and asserts every contribution against the Hermes 0.23.0 SDK contracts, server-renders every `render()` with `react-dom/server` (initial state is seeded through `react-shim.mjs` because `useEffect` never runs in `renderToString`), and — when `happy-dom` is present — mounts each component with `react-dom/client` so the effects run against a fake `ctx.rest` fed by `fixture_bout.json` (recorded from the real `dashboard/plugin_api.py` router through FastAPI's `TestClient`; paths neutralised), clicks every button, fires `plugin.joust.bout.updated` through the fake `ctx.onEvent`, and checks listener disposal; it finishes with static checks (hook placement, list keys, import allowlist, `(--ui-*)` Tailwind tokens against the Desktop stylesheet). Dependencies live **outside the repo**: `npm install --prefix "$TMPDIR/joust-desktop-smoke" react@19 react-dom@19 happy-dom` (or point `JOUST_SMOKE_NODE_MODULES` at any folder containing those packages), then run `node tests/desktop_smoke/smoke.mjs` — or `python3 -m unittest discover -s tests`, which runs `test_desktop_smoke.py` and skips (never fails) when Node or the packages are missing. Exit codes: 0 pass (warnings allowed; `JOUST_SMOKE_STRICT=1` makes them fatal), 1 failed check, 2 prerequisites missing; `JOUST_SMOKE_NO_DOM=1` skips the DOM tier.
